# Places, amenities and official location data (Bern)

Three JSON files in `data/`, all for the bbox S,W,N,E = 46.9, 7.34, 46.99, 7.5 (City of Bern plus edges of Köniz, Muri, Ostermundigen, Ittigen). Not wired into the map yet.

| File | Items | Source | Refresh (Node 24) |
|---|---|---|---|
| `data/amenities.json` | 7,916 | OpenStreetMap (ODbL) | `node tools/build-amenities.mjs` |
| `data/places.json` | 6,685 | OpenStreetMap (ODbL) | `node tools/build-places.mjs` |
| `data/official-places.json` | 5,418 | Stadt Bern geoportal, Kanton Bern, SBB, Velospot | `node tools/build-official-places.mjs` |

Sources and their quirks: [amenities-sources.md](amenities-sources.md). Random-sample location check: [verification.md](verification.md).

## Schemas

`data/amenities.json` = `{ generated, source, items: Amenity[] }`, `Amenity = { id: "node/123", lat, lon, category, name: string|null, opening_hours: string|null, fee: string|null, wheelchair: string|null, website: string|null }`, with `category` in `toilets | drinking_water | pharmacy | hospital | clinic | doctors | library | wifi | atm | supermarket | community_centre`; additive categories (renderers skip unknown ones): `bench | shelter | shower | lockers | post_office | post_box | bank | bureau_de_change | money_transfer | police | townhall | embassy | social_facility | food_sharing | give_box | place_of_worship | dentist | veterinary | aed | emergency_phone | phone_charging | telephone | public_bookcase | internet_cafe | bicycle_repair_station | bicycle_parking | bicycle_rental | recycling | playground | baby_changing | water_point | ticket_machine | ev_charging | car_sharing | taxi | disabled_parking | elevator`. Additive optional fields on every item (string|null, raw OSM values): `address, level, access, operator, phone, description, changing_table, unisex, male, female, toilets_wheelchair, toilets_disposal, drinking_water, covered, backrest, capacity, indoor, check_date`, plus `tags` = raw OSM tag object (minus source*/note*/fixme*/created_by).

`data/places.json` (built by `tools/build-places.mjs`, OSM/ODbL, not wired into the UI yet) = `{ generated, source, bbox: "S,W,N,E", counts: { [group]: { [category]: n } }, items: Place[] }`, `Place = { id: "node/123", lat, lon, group, category, name, brand, operator, address, street, housenumber, postcode, city, phone, email, website, opening_hours, wheelchair, wheelchair_description, toilets_wheelchair, cuisine, diet: {[k]: v}|null, outdoor_seating, takeaway, delivery, payment: {[k]: v}|null, level, internet_access, wikidata, description, check_date, tags?: {raw OSM tags} }`; every field except `id/lat/lon/group/category` may be `null`, `address` is "street housenumber, postcode city". `group` is one of `food_drink | shopping | lodging | attractions_culture | leisure_sport | services | health | worship`; `category` is the raw OSM value (e.g. `restaurant`, `hairdresser`, `hotel`; a few are renamed: `tourist_information`, `coworking`, `embassy`, `recycling_centre`). One category per place (precedence in the script). Named places only, except `parking`, `fuel`, `charging_station`. `tags` is omitted for categories over 1000 items if the file would exceed 15 MB.

`data/official-places.json` (built by `tools/build-official-places.mjs`, official non-OSM data for cross-checking OSM, not wired into the UI) = `{ generated, sources: Source[], items: OfficialPlace[] }`, `Source = { key, name, url, licence, count, fetched_ok, error? }` (a failed source has `fetched_ok: false`, `count: 0`), `OfficialPlace = { id: "<sourceKey>/<native id>", source, lat, lon, category, name, address, opening_hours, wheelchair_or_accessibility, phone, website, email, description, geometry_type, props }`. Every field except `id/source/lat/lon/category/geometry_type/props` may be `null`. Text values are raw German source values (e.g. `wheelchair_or_accessibility` "ja" / "nein" / "unbekannt"). `props` holds every raw source property; polygons are reduced to their centroid with `props.geometry_bbox = [W,S,E,N]`. Sources: Stadt Bern geoportal (`stadtbern.*`, 44 layers), Kanton Bern (`kantonbern.*`: AED, hospitals, elderly and disability care), SBB data.sbb.ch (`sbb.*`), Velospot GBFS (`velospot`, a capacity/vehicle snapshot is in `props.status_snapshot`). Categories include `aed | hospital | elderly_care | disability_services | disabled_parking | acoustic_crossing_signal | tactile_paving | platform_sector_sign | transit_stop | ticket_machine | wifi | bike_share | playground | sports | school | city_office | ...` (list them with `new Set(items.map(i => i.category))`). Bbox 46.9,7.34,46.99,7.5. Licences are per source in `sources[].licence`.
